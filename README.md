# 🧠 PromptOS

> **Your private, offline-first AI operating system.**  
> Planned to be built on Ubuntu & KDE Plasma with [Ollama](https://ollama.com) deeply integrated out of the box.


> **🚧 Early Stage Notice:** This project has **just started**! **Zero lines of code have been written yet, and there is no ISO file available.** Right now, PromptOS is an open concept looking for founding contributors and developers to help build it from scratch.

---

## 💡 The Vision

**PromptOS** is a concept for a custom Linux distribution designed to make local, private Artificial Intelligence accessible to everyone—no complex terminal setup required. 

While cloud AI tools send your personal data to external servers, **PromptOS** will run completely locally on your own hardware. The goal is that from the moment you boot up the system, your personal AI assistant is ready to help you write, code, summarize documents, and answer questions—100% offline and private.

### ✨ Planned Features (The Goal)

* 🤖 **Pre-installed Ollama Engine:** Ollama running seamlessly as a background service from first boot.
* ⌨️ **Instant AI Shortcut:** Press a global hotkey (e.g., `Alt + Space`) anywhere in the OS to summon a clean, floating AI assistant overlay.
* 🚀 **Smart First-Boot Setup Wizard:** Automatically detects your hardware (RAM & NVIDIA/AMD GPU) on first login and helps you download the best AI model for your PC (e.g., Llama, Mistral, Gemma).
* 🎨 **Modern KDE Plasma Desktop:** A familiar, sleek, and customizable desktop environment pre-configured with AI widgets and clean aesthetics.
* 🔒 **Privacy by Design:** Zero telemetry, no required accounts, and all AI processing happens locally on your machine.

---

## 🛠️ Proposed Tech Stack

* **Base OS:** Ubuntu LTS (for rock-solid stability and easy NVIDIA/AMD GPU driver support)
* **Desktop Environment:** KDE Plasma
* **ISO Build Tool:** Cubic or Custom Shell Scripts
* **Local LLM Backend:** Ollama
* **Frontend UI:** Open WebUI / Desktop Plasma Widget
